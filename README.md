# 💻 C Programming

---

## 📚 Topics Covered

The repository is organized into the following topics:

| No. | Topic | Description |
|:---:|---|---|
| 01 | 🟢 Basics of C | Introduction, syntax, variables, data types and input/output |
| 02 | ⚙️ Instructions & Operators | Instructions, arithmetic, relational, logical and other operators |
| 03 | 🔀 Conditional Statements | Decision-making using `if`, `if-else`, nested `if` and `switch` |
| 04 | 🔁 Loops | `for`, `while` and `do-while` loops |
| 05 | ⏭️ Loop Control Instructions | `break`, `continue` and `goto` |
| 06 | 🧩 Functions | Function declaration, definition, arguments and return values |
| 07 | 🔄 Recursion | Recursive functions and problem-solving |
| 08 | 👉 Pointers | Pointer fundamentals, memory addresses and pointer operations |
| 09 | 📦 Arrays | One-dimensional and multidimensional arrays |
| 10 | 🔤 Strings | String handling and standard library functions |
| 11 | 🏗️ Structures | User-defined data types and structures |
| 12 | 📁 File Input & Output | File handling and file operations |
| 13 | 💾 Dynamic Memory Allocation | Dynamic memory management using `malloc()`, `calloc()`, `realloc()` and `free()` |
